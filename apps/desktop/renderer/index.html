      CoachNotes Help

      1. First-time setup

      Open Settings, choose your Root Notes Folder, set Proxy Base URL, and paste your Invite Token. Then click Save & Reindex.

      2. Supported file types

      .md, .txt, .markdown, and .pdf are indexed.

      Unsupported file types are ignored and shown in the status line.

      3. Everfit exports

      If your notes are exported as PDF, place them in your notes folder and click Rebuild Index.

      For best search quality, keep one client per folder when possible.

      4. Creating notes in app

      Use New Note to create markdown files with client, date, tags, and body.

      5. Search and Ask

      Search finds relevant chunks. Ask/Summarize use retrieved sources and provide clickable citations.
