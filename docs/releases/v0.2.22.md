# CoachNotes 0.2.22

## Easier Wrap-Up and Dictation

- End of Day now has an explicit Next action, with navigation kept visible while
  reviewing a long activity history. Update Dashboard & Next processes a note and
  advances; Save Draft & Next preserves the draft and advances without claiming
  the dashboard was updated. Unfinished clients remain pending.
- Schedule a follow-up while reviewing each client. The date defaults to tomorrow
  and is editable. Add Follow-up creates an ordinary Coach To-Do immediately,
  without an AI call, so it appears in Mission Control using the usual due-date
  rules. Unsubmitted follow-up text is preserved; retrying a saved request does
  not create a duplicate task.
- Microphone buttons are now inside ASK requests and follow-ups, note annotations,
  onboarding text, to-do and radar details, narrative profile fields, and coaching
  guidance. Transcription fills editable text and never submits automatically.
- Recording waveform, timer, stop, and retry/discard controls stay inside the
  text box. Failed or interrupted recordings remain available for retry. Closing
  the form stops its microphone; the five-minute recording limit remains.

## Rollout and Boundaries

Desktop-only release. No proxy code, model, prompt, or API-contract changes. The
existing server continues to work with 0.2.21, so installing this update is optional
until the coach is ready. Use Check Updates, download the new build, and quit the
app before replacing it. Builds remain unsigned/unnotarized.

No demo clients or real client data are bundled. Saved drafts are not processed
notes until Update Dashboard is used. Dictation fills a field; that form's normal
save/submit step still applies. The mobile companion idea is deferred and is not
part of this release.
