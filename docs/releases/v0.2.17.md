# CoachNotes 0.2.17

## Weekly Client Review

Mission Control now includes an on-demand weekly briefing across every accepted client.

- Each client receives a concise current focus, weekly assessment, suggested coach focus, attention label, and conservative retention-concern label.
- The report starts with a short practice overview and up to three supported cross-client patterns.
- Clients appear alphabetically by default.
- The same scrolling report can be grouped by retention concern, cohort, or curriculum.
- Client rows retain attention and retention color signals and open the matching client profile.

The first Weekly Review screen is intentionally blank. Demo clients and demo reports are development-only and are never installed with CoachNotes. Click `Generate Weekly Review` to create the first report from the coach's existing accepted clients.

## Scale and recovery

- CoachNotes divides the portfolio into bounded groups of no more than 12 clients or approximately 100,000 context characters.
- At most two assessment requests run concurrently.
- The app remains usable while the report is generated.
- Each completed group is checkpointed locally.
- Closing the app or encountering a later request failure preserves completed groups for `Resume Weekly Review`.
- The previous successful report remains available until every client and the final portfolio synthesis have completed.
- Final synthesis writes only the opening and shared patterns; it cannot relabel client assessments.

A 50-client preview benchmark completed five assessment groups and one synthesis request on their first attempts in 74.1 seconds. It used 47,773 input tokens and 10,590 output tokens and returned exactly 50 alphabetized assessments. Liz's real dashboards may produce different timing and judgments.

## Review checklist

1. Open Mission Control and choose `Weekly Review`.
2. Confirm the initial view is blank and contains no demo clients.
3. Generate the first report and confirm progress advances across all accepted clients.
4. Continue using another CoachNotes view while generation runs, then return to the report.
5. Confirm the final client count matches the accepted-client count.
6. Try A-Z, Retention, Cohort, and Curriculum grouping.
7. Open several client profiles from the report and use Back to return to the same location.
8. Review attention and retention judgments for usefulness, false alarms, and missing context.

## Coordinated rollout

Version 0.2.17 requires its matching proxy deployment for Weekly Review generation. The previous desktop's Weekly Review request format is not compatible with the new batched proxy contract. Existing client records, note updates, Ask, and Mission Control's deterministic tabs are preserved.
