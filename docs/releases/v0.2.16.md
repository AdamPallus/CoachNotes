# CoachNotes 0.2.16

## Main change

Client note updates no longer ask the AI to regenerate the complete dashboard. The proxy returns only affected sections, and the desktop validates and applies those changes locally.

- Unchanged dashboard sections remain untouched.
- New items can be appended to growing sections such as Timeline without returning all prior history.
- Sections that genuinely need consolidation or resolution can still be replaced individually.
- Coach-owned planning and profile metadata remain protected during AI updates.
- Invalid, duplicated, incomplete, or wrongly typed updates are rejected before changing local dashboard data.

## Reliability and diagnostics

- Note-update output allowance is reduced from 9,000 to 4,500 tokens.
- Retry timing now respects an overall budget below Vercel's 120-second limit.
- Incomplete model responses are detected explicitly.
- Privacy-safe logs capture token counts, output size, duration, completion status, and incomplete reason without client content.
- Failed note updates continue to preserve the coach's entered source for retry.

## Coordinated rollout

Version 0.2.16 requires its matching proxy deployment. It is intentionally not compatible with the previous note-update response contract.

1. Download the 0.2.16 installer, but do not open the new version yet.
2. Close the currently running CoachNotes app and confirm readiness for the server cutover.
3. Deploy and verify the matching proxy.
4. Install/open 0.2.16 and run one note-update smoke test.

Initial onboarding, Ask, Mission Control, local data storage, and existing client dashboards are unchanged by this release.
