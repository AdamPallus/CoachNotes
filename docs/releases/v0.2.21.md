# CoachNotes 0.2.21

## Capture and Follow Through

- End of Day in Mission Control helps review clients worked with today, add others from Everfit or meetings, and capture follow-ups one client at a time. Adding an update saves the note and runs the AI dashboard update. Progress is saved locally.
- Dictate records a note with a waveform and timer, then transcribes when stopped. Recording stops at five minutes; start again to add more. The transcript stays editable and is not submitted automatically. Failed transcription preserves the recording for retry.
- Add images by upload, paste, or Screenshot region selection. Images are saved with the source in the vault; AI extracts their visible information for the dashboard update.
- A Weekly Review tab on each client shows their saved assessment and suggested focus without another AI call.
- ASK supports up to five follow-ups, keeps citations and conversation visible, and uses a stable context prefix for prompt caching. Start New ASK for fresh source retrieval.
- Note drafts survive closing and restarting. Successful note submissions are recorded to prevent accidental duplicate retries.
- Error messages use readable light/dark theme colors. ASK avoids exposing internal Electron error wrappers and clarifies citation failures without displaying unverified links.

## Known Follow-Up

Adam found that Save & Close in the daily note editor feels like a loop because it preserves the draft and returns to the same pending client. It does not advance the queue. A clearly named Next action that saves work without claiming the dashboard was updated is recorded for a future UX pass. We are deliberately collecting Liz's feedback before redesigning this flow.

The citation guard can still reject an invalid model reference. Retry is safe; the request and prior conversation remain intact. Prompt clarification reduces one ambiguity but does not guarantee the model will always cite correctly.
