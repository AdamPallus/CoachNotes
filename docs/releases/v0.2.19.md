# CoachNotes 0.2.19

## Reusable Ask Requests

Client Ask now supports saved requests, following the same convenience pattern used for saved note annotations.

- Enter a request and choose `Save request` to keep it available across clients.
- Select a saved request to place it back in the normal Ask box.
- Edit the filled request before asking whenever the client context calls for a change.
- Remove saved requests that are no longer useful.

A useful first preset from Liz's current workflow is: `Give me 1-3 questions to ask based on the recent update.`

Saved requests are local convenience settings on that CoachNotes installation. This release does not change Ask retrieval, context selection, time windows, embeddings, or model behavior.

## Review Checklist

1. Open Ask for a client and enter a request.
2. Choose `Save request` and confirm it appears below the request box.
3. Open Ask for a different client and confirm the saved request remains available.
4. Select the saved request, edit its text, and run Ask normally.
5. Remove a saved request and confirm it no longer appears.

## Rollout

Version 0.2.19 is a desktop-only release. No proxy deployment or coordinated server cutover is required. Existing clients, sources, dashboards, and saved note presets are preserved. The desktop remains an unsigned macOS build, so a first launch may require Right-click and Open.
