# CoachNotes 0.2.18

## Historical Notes

Backdated notes now contribute useful client history without replacing newer current-state information.

- CoachNotes sends the AI a compact date index for prior sources already associated with the dashboard.
- Import order is no longer treated as client chronology.
- Older evidence can enrich the timeline, engagement and progress patterns, program history, recurring themes, and durable profile facts.
- Older evidence should not regress the current Snapshot, reactivate an old coach task, or replace a newer active plan or status.
- When chronology is materially ambiguous, the current coach-reviewed state is preserved.

## Chronological Views

- Client timelines are normalized from oldest to newest, including when the AI tries to append an older milestone.
- The Check-In Archive orders raw sources by the coach-selected source date rather than import time.
- Initial onboarding with multiple sources follows the same event-date rules.

## Weekly Review

- Weekly Review now receives the actual eight most recent dated timeline entries instead of whichever entries were stored first.
- Its retention assessment is explicitly instructed to consider engagement, progress, program-change, and timeline history rather than relying on the current Snapshot alone.
- Source dates are distinguished from the time CoachNotes last processed the dashboard, so importing old material does not look like recent client contact.

Ask retrieval and embeddings are unchanged in this release.

## Review Checklist

1. Add a current note that clearly changes the Snapshot.
2. Add an older backdated note containing a different historical goal or plan.
3. Confirm the current Snapshot and active work remain current.
4. Confirm useful older milestones appear in the correct place on the Timeline.
5. Confirm the Check-In Archive is ordered by source date.
6. Regenerate Weekly Review and check whether its attention and retention assessments reflect the client's trajectory without treating the backfill as recent activity.

## Coordinated Rollout

Version 0.2.18 includes matching desktop and proxy improvements. Existing local client records are preserved. The desktop remains an unsigned macOS build, so a first launch may require Right-click and Open.
